# 贴吧日报订阅源

广东联通吧 / 广东电信吧 / 广东移动吧 的每日新帖与热帖摘要，由私有仓库
`agent-gen` 的定时任务（每天 09:30 北京时间）抓取贴吧公开数据后同步到这里。

RSS 订阅地址（GitHub Pages，任意 RSS App 直接填，无需账号）：

```
https://nobody-0101.github.io/tieba-feed/latest.xml
```

- `latest.xml` — 最新一期，最多 60 条，按最后回复时间排序
- `latest.md` — 同一份内容的可读版（含热帖主楼全文和高赞回帖）
- `history/` — 按日期留档的订阅源

抓取脚本、调度配置和状态文件都在私有仓库里，本仓库只放产出。
