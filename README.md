# 贴吧日报订阅源

广东联通吧 / 广东电信吧 / 广东移动吧 的每日新帖与热帖摘要，由我自己仓库的定时任务每天 09:30（北京时间）抓取贴吧公开数据后同步到这里。

RSS 订阅地址（GitHub Pages，任意 RSS App 直接填，无需账号）：

```
https://nobody-0101.github.io/tieba-feed/latest.xml
```

- `latest.xml` — 最新一期，最多 60 条，按最后回复时间排序；热帖条目内嵌主楼全文和前 40 条回帖，App 里点开就能读完，不用跳贴吧
- `latest.md` — 同一份内容的可读版（含热帖主楼全文和高赞回帖）
- `history/` — 按日期留档的订阅源

抓取脚本和调度配置不在这里，本仓库只放每天的产出。
