# 贴吧日报订阅源

广东联通吧 / 广东电信吧 的新帖与热帖，由定时任务每天 09:30（北京时间）抓取贴吧公开数据后同步到这里。

RSS 订阅地址（GitHub Pages，任意 RSS App 直接填，无需账号）：

```
https://nobody-0101.github.io/tieba-feed/latest.xml
```

- `latest.xml` — 最新一期，最多 60 条，按最后回复时间排序。**每条都内嵌主楼全文和抓到的回帖**，App 里点开就能读完，一条都不用跳贴吧
- `daily/<日期>.html` — 同一期内容的网页版，每条自带全文，条目地址形如 `daily/2026-10-24.html#p<帖子ID>`，RSS 里的 link 就指向这里；按日期留档，旧条目不会失效
- `index.html` — 今天这一期的网页版
- `latest.md` — Markdown 版日报（含热帖主楼全文和高赞回帖）
- `history/` — 按日期留档的订阅源

页面里的正文全部是贴吧公开帖的原样抓取，仅作个人订阅用途，不代表本站立场；贴吧原帖地址以纯文本附在每条末尾（贴吧经常拦机器访问，打不开是常态）。

抓取脚本和调度配置不在这个仓库，这里只放每天的产出。
